# Aurel Estates

A premium, responsive real estate showcase for Aurel Estates, built with React, Vite, Tailwind CSS, React Router, Lucide icons, and Framer Motion.

## Run locally

```sh
npm install
npm run dev
```

Create and lint a production build with:

```sh
npm run build
npm run lint
```

## Demo features

- Home, property collection, property detail, about, contact, and property submission pages.
- Search by location, property type, transaction, and budget; filter, sort, and switch collection layouts.
- Favorite properties, browse a property image gallery, and open the enquiry form.
- Client-side validation and demo success states for contact, enquiry, newsletter, and property listing forms.
- Responsive layouts and mobile navigation.

Property listings, testimonials, advisor details, metrics, and form outcomes are illustrative. This frontend demo has no backend and does not send, store, or publish form submissions.
