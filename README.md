# Aurel Estates

A premium, responsive real-estate frontend built with React, Vite, Tailwind CSS, React Router, Lucide icons, and Framer Motion.

## Run locally

```sh
npm install
npm run dev
```

Create and lint a production build:

```sh
npm run build
npm run lint
```

## Frontend demo

- Home, property collection, property details, about, agents, contact, and saved-home pages.
- Search by location, property type, and sale/rent status; filter by price and bedrooms, sort, paginate, and switch collection layouts.
- Save homes between visits with browser local storage.
- Responsive layouts, mobile navigation, image gallery, and client-side contact forms with validation and confirmation states.

Property listings, advisors, and testimonials are illustrative. This is a frontend-only demo: enquiry and newsletter forms do not send data to a server.
